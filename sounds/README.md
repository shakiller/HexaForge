# Список звуковых файлов для игры HexaForge

Поместите следующие звуковые файлы в папку `sounds/`:

## Основные звуки действий:

1. **grab_piece.mp3** - Взял фигуру (начало перетаскивания)
2. **place_piece.mp3** - Установил фигуру на доску
3. **rotate_piece.mp3** - Повернул фигуру
4. **button_click.mp3** - Клик по кнопке (любая кнопка)
5. **title_fly.mp3** - Полёт названия игры вверх к заголовку
6. **game_over.mp3** - Конец игры (Game Over)
7. **clear_line.mp3** - Удаление одного ряда
8. **clear_multiple.mp3** - Удаление нескольких рядов одновременно

## Звуки появления бонусов (расширяемо):

9. **bonus_spawn_1.mp3** - Появление бонуса (вариант 1)
10. **bonus_spawn_2.mp3** - Появление бонуса (вариант 2)
11. **bonus_spawn_3.mp3** - Появление бонуса (вариант 3)

*Примечание: Система случайным образом выбирает один из этих звуков при появлении бонуса.*

## Звуки действий бонусов (расширяемо):

12. **bonus_diamond.mp3** - Активация алмаза (Diamond Blast)
13. **bonus_bomb.mp3** - Активация бомбы (Shuffle)
14. **bonus_combo.mp3** - Комбо (несколько рядов одновременно)
15. **bonus_streak.mp3** - Серия (Streak)
16. **bonus_multi.mp3** - Мульти-направление (Multi-direction bonus)

---

## Как добавить новые звуки:

1. Добавьте файл в папку `sounds/` с нужным именем
2. В файле `index.html` найдите секцию `// Load sounds` и добавьте:
   ```javascript
   SoundManager.loadSound('новое_имя', 'sounds/новый_файл.mp3');
   ```
3. Используйте звук в коде:
   ```javascript
   SoundManager.play('новое_имя');
   ```
   или для случайного выбора:
   ```javascript
   SoundManager.playRandom(['звук1', 'звук2', 'звук3']);
   ```

## Формат файлов:

Рекомендуется использовать формат MP3 для лучшей совместимости.
Длительность звуков должна быть короткой (0.1-2 секунды) для мгновенной реакции.
